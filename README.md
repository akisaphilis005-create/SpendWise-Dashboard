
# SpendWise Dashboard Shell 💰

## Project Description

SpendWise is a modern personal finance dashboard designed to help users view and organize their monthly budget and expenses.

This project focuses on building a clean, attractive and responsive dashboard using HTML and CSS.

## Features

- Sidebar navigation menu.
- Dashboard header.
- Three financial summary cards.
- Six expense category cards.
- Responsive layout for mobile devices.
- Light and dark theme support.
- Card hover and keyboard focus animations.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- CSS Custom Properties
- Google Fonts

## CSS Techniques

### CSS Grid
Used to create the main dashboard layout, financial summary and expense category cards.

### Flexbox
Used to arrange the sidebar navigation, dashboard header and content inside category cards.

### CSS Variables
Used to define the brand color, accent color, background, surface and text colors.

### Responsive Design
Media queries are used to change the dashboard into a single-column layout on screens below 768px.

### Micro-interactions
Hover and keyboard focus effects use CSS transitions and transform properties with durations below 250ms.

### Dark Theme
The prefers-color-scheme media query changes the theme variables when the device uses dark mode.

## Project Files

- index.html: Contains the dashboard structure and static financial information.
- style.css: Contains the layout, styling, responsive design and animations.
- README.md: Explains the project and technologies used.
